# Shapes & Objects - Kindergarten - Grade 2 - Answer Key

1. What shape is this?
   **Answer:** B) Triangle

2. What shape is this?
   **Answer:** A) Star

3. Which object is a circle shape?
   **Answer:** A) Clock

4. Count the shapes. How many triangles are there?
   **Answer:** 4

5. How many sides does a triangle have?
   **Answer:** 3

6. Which shape is a heart?
   **Answer:** B) Heart

7. A door looks like which shape?
   **Answer:** A) Rectangle

8. Count the shapes. How many squares are there?
   **Answer:** 5

9. Which shape has 4 equal sides?
   **Answer:** B) Square

10. Which shape is DIFFERENT from the others?
   **Answer:** D (the square)
