# Data Sense - Kindergarten - Grade 2 - Answer Key

1. Count the stars. How many stars are there?
   **Answer:** 5

2. Are there more hearts or more stars?
   **Answer:** B) Stars

3. Count the apples. How many apples are there?
   **Answer:** 3

4. Each picture stands for 1 fruit. Which fruit has the MOST?
   **Answer:** B) Bananas

5. Each picture stands for 1 thing. Which row has the LEAST?
   **Answer:** A) Ducks

6. Count the tally marks. How many are there?
   **Answer:** 6

7. Look at the bar graph. Which bar is the TALLEST?
   **Answer:** C) Green

8. Look at the bar graph. How many dogs are there?
   **Answer:** 5

9. Count all the shapes. How many shapes are there in all?
   **Answer:** 7

10. Each picture stands for 1 fruit. Which two rows have the SAME number?
   **Answer:** B) A and C (3 each)
